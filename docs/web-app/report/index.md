# Reports

Reports give you filtered, exportable views of your orders — for sales, installation, preparation and logistics.

## Where to find it

Left-hand navigation → Reports.

## Choose a report

At the top left of the Reports page, use the Reports dropdown to pick the report you want. The page updates to show that report's data.

## Filter the report

Each report has its own filters — set them at the top and the list updates:

| Report | Filters |
|---|---|
| **Sales** | Date range + Segment |
| **Installation** | Date range + Installation provider |
| **Preparation** | Date range |
| **Logistics** | Date range + Logistics company |

## Export

Click the blue Export Data button (top right) to download the current report as an Excel file — the same on every report.
