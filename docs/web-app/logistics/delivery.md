# Delivery

The Delivery screen (Logistics → Delivery) lists your deliveries for a date range. Switch between the Pending and Confirmed tabs; each row shows the order number, customer, delivery address, delivery date, pallet count and status.

![The Delivery screen — list, filters and Export CSV / Print Dockets](../../assets/delivery-list.png)

## Export to CSV

To export the current list, click the green Export CSV button at the top. The filtered table downloads to your machine as a CSV file.

## Print dockets

Click the green Print Dockets button at the top. The delivery dockets are generated as a PDF, which opens in a new tab ready to print.
