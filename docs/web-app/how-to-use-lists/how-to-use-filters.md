# How to use filters

- IdentifyAvailableFilters:Filters are often available to narrow down the list based on specific criteria, such as order status. (See figure below)

- ApplyFilters: Click on the filter option, usually represented by dropdowns or checkboxes, to choose the criteria you wish to filter by.

- ViewFilteredResults:The list will update to show only those records that match the selected filters.

- RemoveFilters: To view the complete list again, clear any applied filters.
