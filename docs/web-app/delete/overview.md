# Overview

The Delete function is a safety net. Deleting a quote, order or schedule removes it from your active lists but doesn't destroy it — the item is moved to the Deleted area and can be [restored](restoring-deleted-items.md) at any time.

You can delete and restore three types of item: **quotes**, **orders** and **schedules**.

- [Deleting an item](deleting-an-item.md) — how to delete, and what it does.
- [Accessing the Delete area](accessing-the-delete-function.md) — where deleted items live.
- [Restoring deleted items](restoring-deleted-items.md) — bring something back.

!!! warning "Delete doesn't void the invoice"
    Deleting an order does **not** cancel or void any invoice already raised for it — the invoice stays live in your accounting system (Sawfish) and the customer can still be chased for it. If an order has been invoiced, [void the invoice](../../payments-accounting/cancelling-and-voiding.md) first, then delete the order.
