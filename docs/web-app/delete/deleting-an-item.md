# Deleting an Item

You can delete a quote, order or schedule when it's no longer needed. Deleting is safe — the item is soft-deleted, meaning it's removed from your active lists but kept, so it can always be [restored](restoring-deleted-items.md).

## How to delete

- **Order or quote** — open it and choose Delete from its actions (⋯) menu, then confirm.
- **Schedule** — delete it from the schedule.

The item is removed from your active lists and moved to the [Deleted area](accessing-the-delete-function.md), where it stays until you restore it.

!!! warning "Delete doesn't void the invoice"
    Deleting an order does **not** void any invoice already raised — the invoice stays live in Sawfish and the customer can still be chased for it. If the order has been invoiced, [void the invoice](../../payments-accounting/cancelling-and-voiding.md) first.

!!! tip "Cancelling a job vs deleting"
    To cancel a job that isn't going ahead, it's usually clearer to void the invoice and move the order to [Lost](../order-management/lost.md) — that keeps it as a record — rather than deleting it outright. See [Cancelling an order & voiding an invoice](../../payments-accounting/cancelling-and-voiding.md).
